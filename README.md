# AI-Based Food Deficiency Estimator and Recommendation System

An AI-powered machine learning system that estimates potential food/nutritional deficiencies based on user-reported problems and provides personalized dietary recommendations.

The project combines data preprocessing, exploratory data analysis, feature engineering, multiple machine learning algorithms, and an interactive Streamlit web application to assist users in identifying possible deficiencies and selecting suitable food sources.

---

## Overview

Nutritional deficiencies can lead to a variety of health-related problems. Identifying potential deficiencies from symptoms and dietary information can help users understand which nutrients may require greater attention.

This project develops a machine learning-based system that:

- Takes user-reported problems/symptoms as input.
- Predicts the most likely nutritional deficiency.
- Compares multiple machine learning algorithms.
- Provides food-based recommendations for the predicted deficiency.
- Presents the complete prediction process through an interactive Streamlit interface.

> **Note:** This project is intended for educational and predictive-analysis purposes and is not a substitute for professional medical or nutritional advice.

---

## Key Features

- Machine learning-based nutritional deficiency prediction
- Multi-class deficiency classification
- User-friendly Streamlit web interface
- Multiple machine learning models for comparison
- Data preprocessing and feature engineering
- Symptom/problem-based prediction
- Personalized food recommendations
- Model evaluation using classification metrics
- Interactive prediction results
